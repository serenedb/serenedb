# Benchmarks

- [Search Benchmark Game](./search-benchmark-game.md) — SereneDB IResearch vs Lucene vs Tantivy on the industry-standard search retrieval benchmark. SereneDB IResearch wins across every query type and collection mode.
- [SearchBench](https://serenedb.com/searchbench/) — full SereneDB benchmark: 92 search and analytics queries over 100M and 1B OpenTelemetry logs against Elasticsearch, OpenSearch, ArangoDB and the Postgres family. Benchmark source at [github.com/serenedb/searchbench](https://github.com/serenedb/searchbench).
