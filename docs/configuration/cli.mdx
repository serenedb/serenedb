The `serenedb` executable runs SereneDB's commands: `serenedb server` starts the SereneDB pg-wire server, and [`serenedb shell`](../clients/serened-shell.md) and [`serenedb psql`](../clients/serened-psql.md) are the command-line clients, which run without starting the server. `serened`, installed next to it, is `serenedb server`.

Use `serenedb --help` to list the commands, and `serened --help` to print the server's command line reference below.
