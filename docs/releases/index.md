# Releases

SereneDB releases are published on [GitHub](https://github.com/serenedb/serenedb/releases). This page lists core database releases only; SereneUI releases use `-ui` tags and are not shown here. Each stable release is also available as a Docker image and via the install script. See [Installation](../installation/index.md) for setup instructions.

For the meaning of version numbers, release lines and related terms, see [Versioning](./versioning.md).
